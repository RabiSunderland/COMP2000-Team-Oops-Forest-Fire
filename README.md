# Team OOPS! Forest Fire Simulation

A watchable forest fire simulation in plain Java.
Lightning starts fires, fire spreads between neighbouring trees depending on
species and wind, trees burn out, and burned trees slowly regrow. The player
moves a water drop around the grid that puts out fires.


Controls: arrow keys move the water, the SPACE key drops it (then begins to recharge for 5 seconds),
W switches the wind on and off.
